Availo
======

Overview
--------

This platform handles the communication with Availo system hosted on the cloud using it api.

Configuration
-------------

Start by adding a plugin that uses this platform


- Host (Required): Cloud hostname (domain)
- Port (Required): Cloud port (usually 443 for HTTPS)
- Account Code: The code is used to identify the account in Availo cloud.
- Account ID: this is the unique identifier of the account in Availo cloud.
- Password: The password to authenticate with Availo cloud.
