System Info
===========

Check your current system information from this page. You can also update the license from here.

To update the license, click on the **UPDATE LICENSE** button and upload the new license file.

.. note::

    The uploaded license file must have the same version of the installed application. The purpose for uploading the license file here is to apply newly purchased plugins and limits. Refer to the :ref:`install-upgrade` section if you need to upgrade the application version.
